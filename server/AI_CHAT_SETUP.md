# 수호봇 AI 상담

현재 로그인한 승인 회원이 사용하는 문서 기반 챗봇입니다. `/chat`에서는 상담 목록과 전체 대화를, 다른 내부 화면에서는 오른쪽 아래 `AI 상담` 버튼으로 작은 상담창을 엽니다. 익명 고객에게 사내 문서를 공개하는 위젯은 아닙니다.

## 설정

기존 Supabase SQL Editor에서 `supabase/migrations/20261011_ai_chat.sql` 전체를 한 번 실행하세요. 기본 `schema.sql` 및 문서 처리 마이그레이션이 먼저 적용된 프로젝트를 대상으로 합니다. SQL은 상담 저장 컬럼, pgvector 검색 함수, 검색 지식 작업 테이블과 권한을 설정합니다. 기존 원문이 있는 문서는 자동으로 지식 생성 대기 상태가 됩니다.

`server/.env`:

```dotenv
SUPABASE_URL=프로젝트_URL
SUPABASE_SERVICE_ROLE_KEY=서버용_키
GEMINI_API_KEY=실제_API_키
GEMINI_MODEL=현재_사용가능한_답변_모델
GEMINI_EMBEDDING_MODEL=gemini-embedding-001
RAG_MIN_SIMILARITY=0.55
```

기존 키·답변 모델은 그대로 사용합니다. 임베딩 모델 기본값은 `gemini-embedding-001`이며 차원은 768입니다. 모델을 변경하면 상담창에서 관리자가 **문서 지식 갱신·재시도**를 눌러 전체 문서를 다시 벡터화해야 합니다. 서로 다른 모델의 벡터는 혼합해 검색하지 않습니다.

서버 재시작 후 문서 검색 지식이 백그라운드에서 만들어집니다. 별도 상시 서버가 필요하며 `KNOWLEDGE_WORKER_ENABLED=false`로 워커를 끌 수 있습니다. 요청 종료 시 실행이 중단되는 서버리스 환경에는 별도 워커 구성이 필요합니다.

## 동작

- 업로드된 문서의 추출 본문을 최대 1,200자 조각으로 나누고 Gemini 임베딩을 생성해 `document_embeddings`에 저장합니다. 문단·페이지·슬라이드·시트 위치를 같이 기록합니다.
- 문서 본문·제목 변경 시 DB 트리거가 갱신 작업을 예약합니다. 삭제하면 관련 벡터와 작업도 삭제됩니다. 벡터 갱신은 문서별 트랜잭션으로 처리합니다.
- 질문과 최근 대화의 질문을 벡터로 바꿔 pgvector 코사인 유사도로 검색합니다. 최대 6곳의 근거를 Gemini에 제공하고 응답을 SSE로 전달합니다. 일반 커피 지식·취향별 원두 추천은 문서가 없어도 Gemini의 일반 지식으로 답합니다. 수호커피의 상품·가격·재고·운영·규정은 관련 문서에 있는 사실만 안내하며 근거가 없으면 담당자 확인을 요청합니다. 이 구분은 대화 맥락을 포함한 시스템 지침으로 적용합니다.
- 문서 검색에 실패해도 일반 커피 안내를 생성합니다. 회사 정보는 검색이 일시적으로 불가능함을 알리고 확인을 요청합니다. 일반 지식에는 문서 출처를 붙이지 않으며 참고 문서에는 실제 답변에서 인용한 문서만 표시합니다.
- 답변 아래 참고 문서에서 출처 위치와 해당 원문을 확인할 수 있습니다.
- **대화 요약**은 현재 대화를 요약하고 상담을 유지합니다. **상담 종료**는 핵심 문의·조치 사항·추가 확인 필요 여부를 저장하고 종료합니다. 종료된 상담에는 새 메시지를 보내지 않습니다.
- 미해결/중요 문의는 요약의 추가 확인 필요 여부에 표시합니다. 디스코드·노션·메일 등 외부 알림은 보내지 않습니다.
- Supabase 상담 기록은 `chat_sessions.transcript` JSONB와 `chat_sessions.summary` JSONB를 사용합니다. 기존 요약 텍스트 컬럼도 함께 갱신합니다. 로컬 JSON 상담 이력은 Supabase로 자동 이전하지 않습니다.
- 회원은 자신의 상담을, 관리자는 전체 상담을 조회할 수 있습니다. 문서 지식 갱신은 관리자 전용입니다. 동일 세션의 메시지·요약·삭제는 DB 임대로 직렬 처리합니다.
- 전송에 실패한 질문은 보존하며 같은 메시지 식별자로 재시도해 중복 질문·답변 저장을 줄입니다. 생성 도중 상담창을 닫아도 서버는 응답 저장을 계속 시도합니다.

질문당 최대 4,000자, 상담당 약 100개 질문을 지원합니다. 문서당 최대 1,500개 조각을 생성하며, 실패한 문서는 관리자 화면에서 원인을 보고 재시도합니다. 문서 검색 준비 상태는 챗봇 상단에서 확인합니다. 최종 답변의 정확도는 원문과 검색 품질에 영향을 받으며 중요한 규정·금액은 참고 원문과 함께 확인하세요.

사용자 요청에 따라 이번 변경의 테스트·빌드·실제 API 호출 검증은 실행하지 않았습니다.

API 참고: [Gemini 임베딩 공식 문서](https://ai.google.dev/gemini-api/docs/embeddings).
